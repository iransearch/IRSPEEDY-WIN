# صفحهٔ انتظار ورود

صفحهٔ ضمیمه به‌صورت UCLoginLoading در محتوای پنجرهٔ اصلی ادغام شده است؛ هدر اصلی و ضریب مشترک 0.905 استفاده می‌شوند و پنجره یا scale دوم ساخته نمی‌شود. لوگوی 720×968 موجود برنامه به کار می‌رود. مدارها، دنباله‌دار مخالف‌گرد، نقاط عنوان و نشانگرهای سه مرحله از XAML مرجع منتقل شده‌اند.

طبق درخواست صریح کاربر، حداقل زمان نمایش **۳ ثانیه** است؛ مقدار ۱٫۵ ثانیه در راهنمای اصلی بسته ملاک نیست. در ورود دستی و ورود خودکار با حساب ذخیره‌شده، زمان بعد از اولین نوبت layout/render اندازه‌گیری می‌شود. درخواست واقعی روی worker هم‌زمان اجرا می‌شود؛ در پایان فقط max(0, 3000 - elapsed) به‌صورت Task.Delay انتظار می‌کشد. بنابراین به ورود کند سه ثانیهٔ اضافه تحمیل نمی‌شود و UI مسدود نمی‌شود. خطای ورود نیز پس از برداشتن صفحهٔ انتظار از طریق پیام موجود دیده می‌شود.

مراحل از جریان واقعی موجود تغذیه می‌شوند: درخواست Login2، پردازش اطلاعات اشتراک/تنظیمات، و ساخت فهرست سرویس‌ها. پاسخ Login2 سرورها را همراه حساب برمی‌گرداند؛ API یا تأخیر ساختگی برای مرحلهٔ سوم اضافه نشده است. مراحل سریع ممکن است بلافاصله عوض شوند؛ حداقل سه ثانیه برای کل صفحه است، نه هر مرحله. تمدید اطلاعات دوره‌ای پس‌زمینه صفحه را نشان نمی‌دهد. منطق قبلی حساب ذخیره‌شده، محدودیت دستگاه و به‌روزرسانی حفظ شده است. دکمهٔ بستن هدر همان رفتار فعلی مخفی‌شدن در tray را دارد؛ این تغییر لغو شبکه به API همگام قدیمی اضافه نمی‌کند.

هنگام انتظار، فرم زیرین غیرفعال است تا ورود دوباره از صفحه‌کلید آغاز نشود. هنگام پنهان‌شدن کنترل، مدار اصلی متوقف و آیتم‌های متحرک مراحل از نمایش جدا می‌شوند.

اعتبارسنجی: کامپایل مستقل WPF کنترل و XAML، بررسی ساختاری پروژه و diff. بیلد کامل net48 و تست تصویری/ورود واقعی روی ویندوز لازم است: ورود زیر سه ثانیه، بالای سه ثانیه، رمز نادرست، حساب ذخیره‌شده، محدودیت دستگاه، اشتراک منقضی و تکرار ورود.
