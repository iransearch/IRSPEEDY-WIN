# صفحهٔ انتظار ورود

صفحهٔ ضمیمه به‌صورت UCLoginLoading در محتوای پنجرهٔ اصلی ادغام شده است؛ هدر اصلی و ضریب مشترک 0.905 استفاده می‌شوند و پنجره یا scale دوم ساخته نمی‌شود. لوگوی 720×968 موجود برنامه به کار می‌رود. مدارها، دنباله‌دار مخالف‌گرد، نقاط عنوان و نشانگرهای سه مرحله از XAML مرجع منتقل شده‌اند.

طبق درخواست صریح کاربر، حداقل زمان نمایش **۴ ثانیه** است؛ مقدار ۱٫۵ ثانیه در راهنمای اصلی بسته ملاک نیست. در ورود دستی و ورود خودکار با حساب ذخیره‌شده، زمان بعد از اولین نوبت layout/render اندازه‌گیری می‌شود. درخواست واقعی روی worker هم‌زمان اجرا می‌شود؛ در پایان فقط max(0, 4000 - elapsed) به‌صورت Task.Delay انتظار می‌کشد. بنابراین به ورود کند چهار ثانیهٔ اضافه تحمیل نمی‌شود و UI مسدود نمی‌شود. خطای ورود نیز پس از برداشتن صفحهٔ انتظار از طریق پیام موجود دیده می‌شود.

مراحل از جریان واقعی موجود تغذیه می‌شوند: درخواست Login2، پردازش اطلاعات اشتراک/تنظیمات، و ساخت فهرست سرویس‌ها. پاسخ Login2 سرورها را همراه حساب برمی‌گرداند؛ API یا تأخیر ساختگی برای مرحلهٔ سوم اضافه نشده است. مراحل سریع ممکن است بلافاصله عوض شوند؛ حداقل چهار ثانیه برای کل صفحه است، نه هر مرحله. تمدید اطلاعات دوره‌ای پس‌زمینه صفحه را نشان نمی‌دهد. منطق قبلی حساب ذخیره‌شده، محدودیت دستگاه و به‌روزرسانی حفظ شده است. دکمهٔ بستن هدر همان رفتار فعلی مخفی‌شدن در tray را دارد؛ این تغییر لغو شبکه به API همگام قدیمی اضافه نمی‌کند.

هنگام انتظار، فرم زیرین غیرفعال است تا ورود دوباره از صفحه‌کلید آغاز نشود. هنگام پنهان‌شدن کنترل، مدار اصلی متوقف و آیتم‌های متحرک مراحل از نمایش جدا می‌شوند.

اعتبارسنجی: کامپایل مستقل WPF کنترل و XAML، بررسی ساختاری پروژه و diff. بیلد کامل net48 و تست تصویری/ورود واقعی روی ویندوز لازم است: ورود زیر چهار ثانیه، بالای چهار ثانیه، رمز نادرست، حساب ذخیره‌شده، محدودیت دستگاه، اشتراک منقضی و تکرار ورود.

هندسهٔ تیک انجام‌شدن مرحله FlowDirection=LeftToRight دارد تا در فهرست RTL آینه نشود.

## شروع برنامه

مسیر فعال شروع برنامه `PrepareFastStartup` است. بدون نشانهٔ حساب ذخیره‌شده، فرم ورود مستقیماً نمایش داده می‌شود. با حساب ذخیره‌شده، `UCLoginLoading` پیش از اولین نمایش پنجره فعال می‌شود؛ لودینگ قدیمی «در حال ورود خودکار» استفاده نمی‌شود. زمان چهار ثانیه از رویداد `ContentRendered` محاسبه می‌شود و آماده‌سازی منابع در پس‌زمینه ادامه دارد.

ورود دستی همچنان درخواست Login2 دارد؛ شروع با حساب ذخیره‌شده همان اعتبارسنجی محلی و گروه‌های رمزگذاری‌شدهٔ قبلی را استفاده می‌کند و درخواست شبکهٔ اضافی ندارد. مراحل آن بررسی حساب محلی، اطلاعات اشتراک و آماده‌سازی لیست سرورهاست. حساب نامعتبر به فرم ورود و حساب معتبر به لیست سرورها هدایت می‌شود؛ الزام به‌روزرسانی نیز حفظ می‌شود. حداقل چهار ثانیه فقط هنگام نمایش صفحهٔ انتظار اعمال می‌شود، نه شروع بدون حساب ذخیره‌شده.
